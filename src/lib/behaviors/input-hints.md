# Input Hints

Use `attributes(kind, h)` on an input or textarea to set its virtual
keyboard, autofill, capitalization, and spelling preferences by purpose.
Use `enter` for the action the Return key should show, such as `next` on
the first field of a form.

CreaseUI Input accepts `hintKind` in Tailwind, StyleX, and Pleat.
`inputMode`, `autocomplete`, and `enterKeyHint` override the preset.
Choose the input's type and validation in the parent view.
