# Crease Tasks: product brief

Crease Tasks is an issue tracker for a small software team. Linear is the reference for how it should feel: calm, dense, fast to read, and quick to change without leaving the list you are in.

Scope of the guide's app: an issue list grouped by status, a personal view, search, editing an issue's status, priority and assignee in place, creating issues, and an issue page. Desktop first, light and dark themes, English. The data is a local sample stored in the browser; there is no backend.

The sample team is Alex Morgan (the signed-in person), Sam Rivera and Jo Tanaka. Issue identifiers start with `CRE`.

Linear is a reference, not a specification. The measurements in [principles.md](principles.md) are our own decisions.
