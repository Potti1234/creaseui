# Supported icons

Generated by `npm run icons:generate`. Import `iconNames`, `hasIcon`, `IconName`, or `icon` from `@/lib/icon`. The default Lucide registry ships this inventory, rather than all Lucide icons. Alternate adapters ship the shared subset listed below. Unknown names render a question-mark glyph with `data-icon-missing`, preserving the caller's accessible label. Use `hasIcon(name)` to choose a domain-specific fallback for dynamic names.
