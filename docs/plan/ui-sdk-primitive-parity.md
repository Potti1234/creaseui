# UI SDK primitive parity audit

The [UI SDK behavior reference](https://ui-sdk.dev/docs/core/behaviors) is the
source inventory. CreaseUI implements the interaction contracts using Foldkit
Schema models, Messages, Commands, Mounts and renderer-owned views. An upstream
factory does not require an identical factory signature here.

| Area                              | CreaseUI entry points and consumers                                                                                                                                                                                                                                                              | Verification and open work                                                                                                                                                                                                                     |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Focus and keyboard                | Roving Focus, Grid Focus, Spatial Focus, Typeahead, Focus Recovery, and Input Hints. Tabs and Toggle Group use Roving Focus. Data Grid reveals its mounted active descendant. Input exposes keyboard and autofill presets in all renderers.                                                      | Navigation and focus tests cover disabled arrow targets, reveal generation, RTL, and focus ownership. The component catalog verifies renderer slot and install coverage. Its
shadcn baseline and passing registry checks do not establish that every UI
SDK interaction option has end-to-end coverage. Use the behavior guides for
per-contract entry points and compatibility limits.

## Foldkit composition

| UI SDK mechanism                             | CreaseUI and Foldkit mechanism                                                                                                                                                     |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Primitive factories and bound slots          | Schema Model and Message definitions, parent update, typed attribute builders, and `defineView`.                                                                                   |
| Implicit event source and scoped attribution | Capture source at the event boundary with Change. Keep reason, source, and attribution in Message or Command arguments across asynchronous work.                                   |
| Component controllers                        | Use Foldkit Ports for external input and Commands or outbound Ports for acknowledgements. Popup Controller correlates requests that need a typed close outcome.                    |
| Page-wide observation                        | Route accepted records through the owning app's update. Observe filters those records and finds elements within a supplied root.                                                   |
| Live and direct attributes                   | Use authored Foldkit attributes for model-driven updates. Scoped Mounts own high-frequency DOM work such as positioning and pointer previews. Release owned resources on teardown. |
| A focused item replaced during a render      | Use Focus Recovery's after-commit Command with the old and replacement IDs. Use `keepFocus` when a synchronous operation moves an existing element.                                |

The browser's automatic body portal fallback requires a renderer-owned outlet
on Foldkit. The popup example uses the native top layer where supported.
Virtualizer can reveal a matched row but does not transfer the browser's find
highlight to the newly rendered text. The Number, Date, Color, Image, and
Testing references are separate utility surfaces.
