## Board parity drift (R3 inputs)

Found by counting `data-slot` values inside the Create board on all three
sites (2026-10-13). These are demo-card drifts, not component drifts:

- `loading-card`: StyleX/Pleat hand-roll pulse placeholders instead of
  `skeleton`, so the board has 0 `skeleton` slots (Tailwind 8). Converting is
  not 1:1 yet: the Tailwind hero overrides the skeleton radius to `rounded-lg`,
  which `ComponentLayoutStyle` (placement-only) cannot express.
- `kitchen-island`: StyleX/Pleat build setting rows and the header switch by
  hand instead of `item*` + `Switch`, so `item-actions` (Tailwind 4) and one
  `switch-field` are missing.
- `toggle-group-item` (outline): Tailwind items compute `shadow-xs`, StyleX/Pleat
  put the shadow on the group only.
- `dropdown-menu-trigger`: StyleX/Pleat also tag a zero-size wrapper with the
  slot; slot-based fixtures must select the button.
