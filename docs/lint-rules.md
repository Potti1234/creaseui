## Application rules

### No raw controls (`no-raw-controls`)

Native buttons, inputs and selects built with h.* instead of the installed control.

#### A hand-built save button

A raw h.button has no focus ring, no variants and no disabled styling, so it drifts from every other button in the app.

Renderers: tailwind, stylex, pleat

Bad (`src/feature.ts`):

```ts
import type { Html, HtmlBuilder } from 'foldkit/html'
import { stack } from '@design/stack'

export const view = <Msg>(h: HtmlBuilder<Msg>): Html =>
  stack({ children: [h.button([], ['Save changes'])] }, h)
```

- src/feature.ts:5:22 `crease/no-raw-controls`: Raw `button` rendering is forbidden in application views (no-raw-controls, contract control.button). Use `button` from './design/button'. Raw rendering is only allowed in exact implementation files registered in crease.lock.json.

Good:

```ts
import type { Html, HtmlBuilder } from 'foldkit/html'
import { button } from '@design/button'
import { stack } from '@design/stack'

export const view = <Msg>(h: HtmlBuilder<Msg>): Html =>
  stack({ children: [button({ children: ['Save changes'] }, h)] }, h)
```

### Lint scope baseline (`scope`)
