# Package releases

For changes to `@creaseui/lint`, run `npm run changeset`, select that package,
and describe the change. Commit the generated changeset with the implementation.

The release workflow opens a Version Packages PR. Merging that PR publishes the
new lint package version. Only `@creaseui/lint` is published.

See [the release guide](../docs/releasing.md) for first-publish setup and checks.
